# Комиссии, вес блоков и нагрузка на узлы: сценарная модель

Этот эксперимент дополняет `bitcoin_pqc_size_model.py`. Он читает уже сохранённый `data/bitcoin_pqc_size_model.csv` и не делает повторных запросов к Blockstream Esplora.

## Запуск

Из корня репозитория:

```bash
python -m pytest -q tests/test_bitcoin_pqc_network_impact.py
python -m experiments.transaction.bitcoin_pqc_network_impact
```

Для построения PNG установите matplotlib:

```bash
python -m pip install matplotlib
```

## Методика и ограничения

- Комиссия рассчитывается как `ceil(vsize × ставка sat/vB)`. Это арифметическое сравнение при фиксированной ставке, а не прогноз того, как изменится рынок комиссий.
- Вес Bitcoin-транзакции измеряется в WU; для оценки вместимости используется лимит блока 4 000 000 WU. Для каждого сценария средний вес выборки экстраполируется на блок, условно заполненный транзакциями такого среднего размера.
- Доля 25% означает гипотетическую долю транзакций, мигрировавших на новый формат. Модель линейно интерполирует средний размер и вес между исходными и моделируемыми средними значениями выборки.
- Расчёт числа транзакций в блоке — верхняя оценка: не учитываются coinbase-транзакция, заголовок блока, commitment-данные, реальное распределение размеров и ограничения валидного формата транзакций.
- Оценка хранения предполагает 144 полностью заполненных блока в день, 365 дней в году, отсутствие pruning и сжатия. Она учитывает только сериализованные данные транзакций, а не реальное место на диске, индексные базы, журналы, резервные копии или сетевой трафик узла.
- Комиссии и объём данных рассчитаны на основе текущей выборки. Их нельзя автоматически переносить на весь Bitcoin.
- В исходной модели заменяются только элементы, структурно похожие на strict-DER ECDSA-подписи; скрипты Bitcoin не исполняются, Schnorr/Taproot не заменяются.
- Реальный переход Bitcoin на ML-DSA потребовал бы изменения формата транзакций и правил консенсуса. Этот эксперимент не создаёт действительные ML-DSA-транзакции и не доказывает квантовую стойкость сети.

В научной работе описывайте результаты как **сценарные оценки при явно заданных допущениях**, а не как измеренный рост реальных комиссий или прогноз фактического размера блокчейна.
