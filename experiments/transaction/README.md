# Bitcoin ML-DSA-65 size model — инструкция по запуску

Этот эксперимент получает реальные подтверждённые транзакции Bitcoin через публичный API Blockstream Esplora и строит **контрфактическую модель**: распознанные ECDSA-подписи заменяются данными размером подписи ML-DSA-65 (3309 байт по [NIST FIPS 204](https://doi.org/10.6028/NIST.FIPS.204)). Затем пересчитываются размер сериализованной транзакции, вес и виртуальный размер (vsize).

> **Ограничение:** это не изменение блокчейна Bitcoin и не рабочая реализация транзакций с ML-DSA. Распознавание ECDSA выполняется по структуре DER и эвристикам; подписи Schnorr/Taproot не заменяются. Результаты описывают только выбранную выборку и не доказывают конкретное увеличение комиссии.

## 1. Требования

- Python 3.10 или новее.
- Git — если вы ещё не скачали репозиторий.
- Подключение к интернету для API Blockstream Esplora.
- matplotlib для PNG-графика (необязателен для вычислений).
- pytest для запуска тестов (необязателен для самого эксперимента).

Сам скрипт использует стандартную библиотеку Python; внешняя криптографическая библиотека не требуется.

## 2. Получить проект

Если репозиторий ещё не скачан:

~~~bash
git clone https://github.com/AL3XZIG/quantum-crypto-research.git
cd quantum-crypto-research
~~~

Если проект уже есть, перейдите в его корневую папку и обновите main:

~~~bash
git switch main
git pull
~~~

## 3. Создать окружение и установить зависимости

### Windows (PowerShell)

~~~powershell
python -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
python -m pip install matplotlib pytest
~~~

Если PowerShell блокирует активацию окружения, используйте CMD:

~~~cmd
.venv\\Scripts\\activate.bat
python -m pip install matplotlib pytest
~~~

### Linux (Mint, Ubuntu, Debian)

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install matplotlib pytest
~~~

Если команда создания окружения недоступна, установите системный пакет python3-venv через пакетный менеджер вашего дистрибутива.

## 4. Запустить тесты

Из корневой папки репозитория:

~~~bash
python -m pytest -q tests/test_bitcoin_pqc_size_model.py
~~~

Тесты работают офлайн на синтетических данных. Они проверяют разбор и сериализацию транзакций и распознавание тестовых ECDSA-подписей, но не проверяют доступность API и не заменяют запуск на живых данных.

## 5. Получить результаты из API

Для первого запуска рекомендуется 100 транзакций:

~~~bash
python -m experiments.transaction.bitcoin_pqc_size_model --count 100
~~~

Для выборки из 1000 транзакций:

~~~bash
python -m experiments.transaction.bitcoin_pqc_size_model --count 1000
~~~

Чтобы увеличить интервал между запросами:

~~~bash
python -m experiments.transaction.bitcoin_pqc_size_model --count 100 --delay 0.2
~~~

По умолчанию программа использует API https://blockstream.info/api, запрашивает недавние блоки и получает сырую сериализацию транзакций. Для работы нужен доступ к сети; API может ограничивать запросы или быть временно недоступен. Скрипт повторяет некоторые временные ошибки, а отдельные неудачно обработанные транзакции пропускает с предупреждением.

### Полезные параметры

- --count 100 — сколько идентификаторов транзакций запросить.
- --delay 0.15 — задержка между запросами в секундах.
- --signature-bytes 3309 — размер моделируемой подписи; не меняйте его без объяснения методики.
- --api URL — альтернативный совместимый Esplora API.
- --output PATH, --summary PATH, --table PATH, --figure PATH — пути выходных файлов.

Посмотреть все параметры:

~~~bash
python -m experiments.transaction.bitcoin_pqc_size_model --help
~~~

## 6. Где искать файлы

После успешного запуска:

| Файл | Содержание |
|---|---|
| data/bitcoin_pqc_size_model.csv | Данные каждой обработанной транзакции: исходные/смоделированные размеры, вес, vsize и изменения |
| data/bitcoin_pqc_size_summary.json | Сводная статистика и ограничения модели |
| results/tables/bitcoin_pqc_size_summary.csv | Компактная сравнительная таблица для Excel/LibreOffice Calc |
| results/figures/bitcoin_pqc_size_comparison.png | Один график: исходный размер против смоделированного и распределение процентного роста |

Если matplotlib не установлен, расчёты и CSV/JSON/таблица всё равно могут быть сохранены, но PNG-график будет пропущен. Если не распознано ни одной ECDSA-подписи, график также не строится.

## 7. Как интерпретировать результаты

1. Проверьте в JSON поля analyzed_transactions и transactions_with_recognized_ecdsa_signatures.
2. Убедитесь, что в итоговом CSV есть строки с данными, а не только заголовок.
3. Для графика используются только транзакции, где распознана хотя бы одна ECDSA-подпись.
4. Средние значения общей сводки включают все обработанные транзакции, в том числе те, где подпись не была распознана и размер не изменился.
5. Сохраните дату/высоту блока из JSON, размер выборки, параметры запуска и версии Python/зависимостей для воспроизводимости.

**Не переносите результаты одной выборки на весь Bitcoin.** Структурное распознавание не выполняет Bitcoin Script и не подтверждает, что гипотетическая транзакция с ML-DSA была бы допустима по правилам консенсуса. Не утверждайте, что комиссия вырастет на тот же процент: фактическая комиссия зависит от виртуального размера и рыночной ставки комиссии.

## 8. Если возникла ошибка

- **Timeout / HTTP 429 / 5xx:** подождите и повторите запуск с большим --delay, например --delay 0.5.
- **No transactions could be analyzed:** проверьте доступ к API и повторите попытку позже.
- **PNG не создан:** установите matplotlib в активное Python-окружение.
- **Импорт модуля не найден:** запускайте команду из корневой папки репозитория, а не из experiments/transaction.
- **Тесты не проходят:** сохраните полный вывод команды pytest и проверьте, что используете актуальную ветку main.

Перед включением чисел в исследовательскую работу сначала запустите эксперимент и проверьте полученные CSV, JSON и PNG. Не используйте вымышленные или непроверенные результаты.


## Дополнительный эксперимент: комиссии, вес блоков и нагрузка на узлы

Это отдельный CLI-эксперимент. Он использует уже собранный `data/bitcoin_pqc_size_model.csv`, не требует веб-интерфейса и после запуска печатает сравнение и выводы в CMD/терминал.

Из корня репозитория:

~~~cmd
.venv\\Scripts\\python.exe -m experiments.transaction.bitcoin_pqc_network_impact
~~~

Либо запустите `run_bitcoin_pqc_network_impact.bat`.

Если CSV ещё нет, сначала соберите выборку транзакций:

~~~cmd
.venv\\Scripts\\python.exe -m experiments.transaction.bitcoin_pqc_size_model --count 500
~~~

Программа автоматически создаёт отчёт `results/bitcoin_pqc_network_impact_report.md`, таблицы CSV в `results/tables/`, JSON-сводку и три PNG-графика в `results/figures/`.

Проверка расчётной модели:

~~~cmd
.venv\\Scripts\\python.exe -m pytest -q tests/test_bitcoin_pqc_network_impact.py
~~~

Все комиссии считаются при фиксированной ставке sat/vB. Оценка вместимости — верхняя граница по среднему весу выборки; оценка хранения предполагает постоянно полные блоки и не измеряет реальный объём диска или сетевой трафик узла.
