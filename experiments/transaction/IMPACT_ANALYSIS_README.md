# Анализ комиссий, веса блоков и хранения узла Bitcoin

Этот дополнительный эксперимент использует CSV, созданный скриптом `bitcoin_pqc_size_model.py`, чтобы оценить три последствия контрфактической замены распознанных ECDSA-подписей на payload размером ML-DSA-65 (3309 байт):

1. оценочные комиссии при заданной ставке в sat/vB;
2. вместимость блока при неизменном лимите веса 4 000 000 WU;
3. ориентировочный прирост дискового хранения блокчейна.

**Это сценарная модель, не прогноз реальных комиссий и не реализация постквантового Bitcoin.** Комиссия зависит от рыночной ставки, а не только от размера транзакции. Размеры подписей и веса берутся из структурной модели, которая не исполняет Bitcoin Script. Текущие правила консенсуса не допускают простой замены ECDSA на ML-DSA.

## Запуск

Сначала получи CSV исходного эксперимента:

```bash
python -m experiments.transaction.bitcoin_pqc_size_model --count 500
```

Затем запусти сценарный анализ:

```bash
python -m experiments.transaction.bitcoin_pqc_impact_analysis
```

Для тестов:

```bash
python -m pytest -q tests/test_bitcoin_pqc_impact_analysis.py
```

Нужен Python 3.10+. Для PNG-графиков установи `matplotlib`; без него CSV-таблицы всё равно создаются.

## Методика и ограничения

- Оценочная комиссия вычисляется как `ceil(vsize × ставка sat/vB)`. Это не фактическая комиссия исторической транзакции и не оценка её приоритета в mempool.
- Лимит веса блока задан как 4 000 000 WU. Оценка количества транзакций по среднему/медианному весу не учитывает coinbase, заголовок, распределение типов транзакций и прочие накладные расходы.
- «Упаковка выборки» рассматривает выборочные транзакции как один поток в порядке CSV. Это гипотетический тест, а не реконструкция исходных блоков.
- Режим `equal_transaction_throughput_unconstrained` сохраняет одинаковое число транзакций в день и намеренно игнорирует лимит блока; его нельзя трактовать как выполнимый прогноз при неизменных правилах Bitcoin.
- Режим `fixed_block_weight_capacity_estimate` предполагает 144 полных блока в день и использует средние значения размера и веса выборки. Он исключает coinbase, заголовки, другие накладные расходы и особенности хранения конкретного узла.
- Результаты зависят от выборки. Указывай размер выборки и высоту tip из JSON исходного эксперимента при использовании чисел в исследовательской работе.

Все полученные CSV и PNG следует проверять после запуска; не подставляй вымышленные результаты в научную работу.
